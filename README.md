HEATWAVE: Coral Vista — an original open-world crime game in the browser (three.js): a sun-soaked coastal city on foot and by car, traffic and pedestrians, cars to steal, a 0–5 star wanted level with CVPD patrol cars, officers and a helicopter, five story missions with Rafa Sol and Nina Vega, street races and taxi jobs, a HUD with minimap, full city map, save/load and synthesized audio.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```
